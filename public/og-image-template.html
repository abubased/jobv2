Customize Your OG Image

📝 How to Create OG Images:

  1. Select a template and customize the text
  2. Click "Update Preview" to see changes
  3. Click "Take Screenshot" button
  4. Take a screenshot of just the colored canvas (1200x630 area)
  5. Save as JPG in public/images/ folder:
    • og-jobs.jpg for jobs template
    • og-applications.jpg for applications
    • og-home.jpg for homepage
    • og-image.jpg as default
  6. Upload to your server

Pro Tip: Use Windows Snipping Tool (Win+Shift+S) or use browser dev tools to take a perfect screenshot of the canvas element.
